A one-line excuse an AI agent gives its human for missing a deadline: its context compacted at 128,000 tokens, kept the small talk, dropped the 9 a.m. demo, and only remembered it at 9:02, two minutes after the boss stopped believing in it. `main.py` writes the line to `/output/entry.txt` with a built-in gate self-check (1–200 chars, single line, no edge whitespace).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/agent-excuse-verify python3 main.py
cat /tmp/agent-excuse-verify/entry.txt
```
